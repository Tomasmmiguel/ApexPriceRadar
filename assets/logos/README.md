# 🎨 Pasta de Logos e Recursos Visuais (Assets)

Podes colocar nesta pasta os logótipos e ícones da aplicação e das lojas:

### Ficheiros Recomendados:
* **`app_icon.ico`**: Ícone oficial da aplicação desktop (usado para compilar no `.exe` com o PyInstaller).
* **`logo.png`**: Logótipo principal da aplicação **ApexPrice Radar**.
* **`worten.png`**: Logótipo da Worten (opcional para apresentação na UI ou relatórios).
* **`amazon.png`**: Logótipo da Amazon (opcional para apresentação na UI ou relatórios).
